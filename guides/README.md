# Use guidelines

Two print-ready booklets, built from live screenshots of the studio.

- [ASLP-Student-Guide.pdf](./ASLP-Student-Guide.pdf) — students: home, 3D stage, labels, layers, workbook, phone and tablet.
- [ASLP-Faculty-Guide.pdf](./ASLP-Faculty-Guide.pdf) — faculty: lesson plan, print sheets, OSCE rubric, projector, RCI mapping.

Rebuild after UI changes:

    node capture.mjs
    python3 build_guides.py
