# Recordings for the Speech & Articulation lab

Drop MP3 files here with these exact names. The Play button in the phoneme card switches on automatically when the file exists.

Tips: record in a quiet room, 44.1 kHz mono, about 1 s per sound (sound in isolation, or CV syllable with /a/ for stops), peak-normalise to -3 dBFS, then export MP3 (128 kbps).
