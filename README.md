# ASLP Anatomy Studio

Browser-based 3D teaching studio for **B.ASLP (RCI 2024–25)** and postgraduate audiology / speech-language pathology.

Version 1.1 loads **reconstructed dissection meshes** (BodyParts3D / Z-Anatomy, CC BY-SA) for pinna, temporal bone, ossicles, cochlea, larynx, tongue–pharynx, and language cortex. It is not Elsevier Complete Anatomy, not a surgical navigator, and not a substitute for cadaver teaching.

## What is included

- 17 curriculum modules (M00–M16) mapped to RCI papers B1.3, B1.4, B2.4, B4.1–B4.3, B5.1–B5.3, B6.1–B6.3
- Real selectable 3D parts: click a mesh or a name in **Dissection parts** to isolate it
- Layer toggles: surface, bone, muscle, membrane, nerve, vessel, physiology
- Left / right laterality
- Physiology overlays on the real anatomy
- UG and PG outcomes, worksheets, OSCE stations, viva frames
