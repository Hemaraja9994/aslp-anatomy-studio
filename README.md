# ASLP Anatomy Studio

Browser-based 3D teaching studio for B.ASLP (RCI 2024-25) and postgraduate audiology and speech-language pathology.

Version 1.0 uses educational schematic 3D models for teaching and viva preparation. It is not a surgical navigator.

## Use
Open the deployed Vercel URL, or preview locally:

```bash
python3 -m http.server 4173
```

## Deploy
Vercel: framework Other, empty build command, output `.`
Cloudflare Pages: empty build command, output `/`
